# 万圣宝石夜 · Dabaoshi

HTML5 Canvas 双角色协作合成游戏。高家声由玩家控制；穿吸血鬼装的 Jimmy 是会拍动小翅膀、自动选落点投掷的 AI 队友。两人共用一座宝石塔和得分。

## 试玩

下载本仓库，直接用浏览器打开 `index.html`。无需安装依赖。

- 移动鼠标或拖动手指瞄准，松开时投放高家声抱着的宝石。
- 键盘 ← / → 调整落点，空格投放，R 重新开始。
- Jimmy 每约 4 秒自动寻找相同等级宝石附近的落点并投掷。
- 两颗相同等级的宝石碰撞会合成。共有 11 级；第 11 级再合成会清除两颗并获得分数。
- 宝石在警戒线上方持续约 2.5 秒，或者投放入口被占据时，游戏结束。
- 最高分保存在当前浏览器的本地存储中。

## 实现

宝石使用不同边数的凸多边形。碰撞检测使用分离轴定理（SAT），并处理墙壁、底板、弹性和角速度。宝石等级越高，切面、光环和星光装饰越丰富。角色和背景均由 Canvas 绘制，因此目前不依赖外部图像或游戏引擎。

项目中已有来自 [awesome-gamedev-agent-skills](https://github.com/gamedev-skills/awesome-gamedev-agent-skills) 的 `game-feel`、`game-ui-ux` 等项目级 Skills。本次参考了其中的反馈与响应式布局建议，没有新增或运行第三方 Skill 脚本。
