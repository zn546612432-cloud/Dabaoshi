# 万圣宝石夜 · Dabaoshi

HTML5 Canvas 双角色协作合成游戏。高家声是玩家控制的狼人；Jimmy 穿吸血鬼服装、扇动翅膀飞行，由 AI 自动投掷。两人共用宝石塔与分数。

## 试玩

下载仓库后，直接用浏览器打开 `index.html`。无需安装依赖。

- 鼠标移动或手指拖动可瞄准，点击或松开时投放宝石。
- 键盘 ← / → 调整落点，空格投放，R 重新开始。
- 两位角色抱着的宝石会沿弧线飞入场内，再进入重力碰撞；Jimmy 每约 4 秒选择落点投掷。
- 同等级宝石相碰会合成。共有 11 级，依次融入糖果、南瓜、幽灵、蝙蝠、女巫帽、魔药、血月、夜星、骷髅、王冠和万圣纹章。
- 宝石在警戒线上方持续约 2.5 秒，或者投放入口被占据时，游戏结束。
- 最高分保存在当前浏览器的本地存储中。

## 实现与素材

宝石使用不同边数的凸多边形。碰撞检测使用分离轴定理（SAT），并处理墙壁、底板、弹性和角速度。合成有粒子、震动和连击得分。角色透明图片根据用户提供的双人参考图生成，已放在 `assets/`；角色投掷动作、Jimmy 翅膀、宝石弧线、轨迹和背景装饰由 Canvas 绘制。图片加载失败时会退回简化角色绘图。

动画方案参考了 [Tween.js](https://github.com/tweenjs/tween.js) 的缓动思路，并调研了 [PixiJS](https://github.com/pixijs/pixijs) 与 [maxrects-packer](https://github.com/soimy/maxrects-packer)。本版直接使用 Canvas 和少量自写缓动，以保持项目零依赖；没有复制这些项目的代码或安装新库。项目已有的第三方 Skills 来自 [awesome-gamedev-agent-skills](https://github.com/gamedev-skills/awesome-gamedev-agent-skills)，本次未新增 Skills。
